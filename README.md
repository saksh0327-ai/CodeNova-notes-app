Notes Application

A simple Notes Application backend built using Python and FastAPI.

Features

- Create a note
- View all notes
- Update an existing note
- Delete a note

Technologies Used

- Python
- FastAPI
- Uvicorn

How to Run the Backend

1. Open the terminal in VS Code.
2. Navigate to the backend folder.
3. Install dependencies using "pip install -r requirements.txt".
4. Run the application using "python -m uvicorn main:app --reload".
5. Open "http://127.0.0.1:8000/docs" in your browser.
